# EHR System over Blockchain — Curated EHRs

BTech Final Year Project — CCE 2020

This repository contains curated Electronic Health Records (EHRs) used to test and validate the system proposed in our paper, **"Verified Access to EHR over Blockchain and IPFS with Lit Protocol Encryption"** (2024 IEEE ICBDS). Records were curated using data sourced from MIMIC-III and populated to reflect the range of medical data types the system is designed to handle.

Main implementation repository: https://github.com/VSrihariMoorthy/EHR-system-over-Blockchain-HealthVault
